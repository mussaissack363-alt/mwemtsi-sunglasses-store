# Project Skills & Guidelines

## UI/UX Design System (UI/UX Pro Max)
- Always use Tailwind CSS with a modern dark-mode aesthetic.
- Ensure all interactive elements have explicit hover, focus, and active states.
- Follow mobile-first responsive design patterns.
- Use accessible color contrast ratios and semantic HTML tags.

## Framework & Coding Standards
- Implement strict type-checking.
- Structure components with clear separation of logic and presentation.

## Creative Technical Stack
- Framework: Next.js (App Router) or Vite + React
- Styling: Tailwind CSS (Strict dark mode, deep rich charcoal/black backgrounds like `#0a0a0a`, atmospheric glow/light leaks)
- 3D & Animation: Three.js, @react-three/fiber, @react-three/drei, and GSAP (GreenSock) for cinematic scroll-triggered animations.

## UI/UX Art Direction (Oryzo Style)
- **Aesthetic:** Cinematic, minimal, ultra-high-end tech product landing page.
- **Typography:** Bold, oversized display typography paired with clean, lightweight technical data text.
- **Interactivity:** Every section must feel responsive to mouse movement (parallax, subtle tilt, or orbit controls).
- **Transitions:** Seamless integration between 3D canvas viewport elements and flat HTML structural UI layout overlays.
